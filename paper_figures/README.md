# Figures for the technically checked manuscript

Figure_3.png: four recorded-data numerical parity panels.
Figure_4.png: phase-label confusion matrix and classification performance.
Figure_6.png: within-case mixing-enthalpy and atomic-size-mismatch standard deviations, shown as box plots with all case points.

All three images were regenerated from the archived analysis tables and matched the saved image references used in the technically checked manuscript pixel for pixel. The comparison is to that reviewed version, not the earlier synthetic manuscript figures. PNG files retain 300 dpi export metadata.

From github_v2, install requirements.txt and run:

    python regenerate_paper_figures.py

No API calls are required. Exact pixels were verified with Python 3.12.14 and the pinned dependencies on Windows. Future API outputs are not guaranteed to be identical.
